# Sorpresa para Siddhartha ♡

Mini sitio responsive para revelar una invitación al concierto de Siddhartha el 11 de diciembre de 2026.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: diseño responsive.
- `script.js`: interacción para revelar la sorpresa.

## Personalizar
Edita `index.html` para cambiar los textos. Si ya conoces la ciudad, el recinto o la hora, podemos añadirlos a la tarjeta de la sorpresa.

## Publicar gratis con GitHub Pages
1. Crea un repositorio nuevo en GitHub, por ejemplo `sorpresa-siddhartha`.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
3. Entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, guarda.
6. GitHub te dará una URL pública. Ábrela en tu celular para comprobarla.
7. Genera un QR usando esa URL exacta y pruébalo con la cámara antes de imprimirlo.

No subas datos privados. Cualquiera que tenga el QR o la URL podrá ver la página.
